How it works

Three steps. No screenshots to mark up by hand.

1

Pin or draw.

Click any element to pin a note, or draw over an area with the red pen. A closed loop takes everything inside it.

2

Write what should change.

Type your comment and press Enter.

3

Paste into your agent.

The prompt is already on your clipboard, with a screenshot of the spot and your mark drawn in red.

Try it

Annotate a dashboard, right here.

The full widget on a demo admin dashboard: tray, pin, pen, comment box, pins that stay, the notes panel and a real marked screenshot.

The prompt AAT builds
Open the tray on the dashboard's right edge. Pick the pin and click anything, or pick the pen and circle a few things. Write what should change and press Enter. The prompt, and the screenshot with your mark, appear here.

With the tray closed you can play with the page. This playground is a plain JavaScript port of the widget; inside a Next.js app in development, AAT also lists the React components. Notes stay in this browser.

Features

Small tool, the right details.

Pin and pen.

Pin one element, or draw over many.

Agent-ready prompts.

Selectors, React components, classes and current styles, in plain text.

Marked screenshots.

Cropped around your mark, saved into your project on localhost.

Pins that stay put.

Notes reappear on their element after reload and follow it while scrolling.

Batch it.

Copy every note on a page, or all of them, as one prompt.

Safe by design.

Admin only, never downloaded by visitors, never changes your page, notes stay in your browser.

Install

Add it in one sentence.

AAT ships as a Claude Code skill. Copy it into your skills folder and ask Claude Code to add it.

$ git clone https://github.com/adigold/AAT-Tool.git ~/.claude/skills/admin-annotation-tool
Then, in your project: "Add AAT to this app"

Prefer doing it by hand? Follow SKILL.md in the repo. Requires Next.js App Router, React and Tailwind CSS v4.
