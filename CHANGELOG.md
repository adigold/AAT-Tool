# Changelog

All notable changes to this project are listed here.

## 1.0.0 (2026-10-16)

First public release.

- Floating admin tray with Pin, Pen and Notes.
- Agent-ready prompt: page, viewport, and per element the text, selector, React components, attributes, classes, size, position and current style.
- Pen notes with closed-loop selection and the shared parent section.
- Marked screenshots, saved into the project on localhost.
- Pins that persist and follow their element.
- Notes panel: this page or all, copy one, copy all as one prompt, delete, clear.
- Admin gate with lazy loading and an error boundary.
- Distributed as a Claude Code skill.
