# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give specific and kind feedback, and keep discussions about the work. Harassment of any kind is not tolerated.

To report a problem, contact the maintainer through [github.com/adigold](https://github.com/adigold). Reports are handled privately.
